# 📱 Hexadecimal Addition Calculator 🔢

A simple, interactive calculator built with **HTML**, **CSS**, and **JavaScript**, specifically designed to perform **hexadecimal addition**. This project allows you to add numbers in **base 16** easily, while providing a clean and responsive interface.

---

## 🎯 Features

- ➕ **Hexadecimal Addition**: Add numbers in base 16 with instant results.  
- 📱 **Responsive Design**: Works across desktops, tablets, and mobile devices.  
- 🎶 **Optional Sound Effects**: Button clicks can trigger sound effects for interactive feedback.

## 📥 Installation

To run a local copy of the hexadecimal calculator:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/Jasu-html/HEX-CAL.git
   
2. **Navigate into the project folder:**
   ```bash
   cd HEX-CAL
   ```
3. **Open the index.html file in your browser:**
   ```bash
   Open the file directly to start using the hexadecimal calculator.
   ```
---

## 🧑‍💻 How to Use

1. Open the `index.html` file in your browser.  
2. Enter hexadecimal numbers (0–9 and A–F) using the calculator buttons.  
3. Click the **+** button to perform addition.  
4. Press **=** to get the result in hexadecimal.  
5. Press **C** and **AC**  to clear the input.  
6. Optional: Enjoy sound effects when clicking buttons 🔊 (if enabled).
